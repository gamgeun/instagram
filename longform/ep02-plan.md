# 2편 계획 (B 방향: 사건·수수께끼) — "코닥은 정말 디지털카메라를 숨겼을까?"

## 알려진 이야기 vs 기록
- 알려진 이야기: 1975년 코닥이 세계 최초 디지털카메라를 만들었지만, 필름이 안 팔릴까 봐 숨겼고, 그래서 2012년 파산했다.
- 기록: 
  - 1975년 코닥 기술자 스티븐 새슨이 시제품을 만들었다. 0.01메가픽셀(100×100) 흑백, 카세트테이프에 저장, 한 장 기록에 23초. 무게는 자료마다 3.6kg~4kg대로 다름. [P1][P2]
  - 경영진 반응: 새슨의 회상으로 "귀엽지만 아무한테도 말하지 마라"(뉴욕타임스 인터뷰로 알려짐, 원문 미확인). [P1][P3]
  - 1988년부터 휴대용 시제품을 만들었고, 1991년 업무용 디지털카메라 DCS-100을 발표했다. [P4]
  - 몰락 원인을 "디지털을 숨겨서"로 보는 데 반대하는 분석도 있다(필름 수익이 줄면서 전환 비용을 버틸 여력이 없었다는 해석). [P5][P6]
- 구성: 알려진 이야기로 시작 → 1975년 실험실 장면 → 기록을 하나씩 확인 → "숨겼다"보다 복잡한 진짜 이야기.

## 확인이 더 필요한 것
- "귀엽지만 말하지 마라" 원문(뉴욕타임스 기사)
- DCS-100 발표 시기와 사양(코닥 기록)
- 경영 분석은 학술 자료(경영사 연구)로 보강
