# 6개월 제안 (2026-11-17, 사용자 확인 전)

## 한 줄
AI로 얼굴 없는 영상 채널을 만들고 운영하는 과정을 실제 숫자와 함께 보여 주고(광고), 그 과정에서 만든 도구를 키트로 판다(상품).

## 왜
- 가짜가 없다: 크레딧, 렌더 시간, 실패(쇼츠 무음 버그), 조회수를 그대로 보여 준다.
- 수요: 한국어 "클로드 영상 편집 자동화" 11만~23만, "AI 활용법" 중앙값 14만·채널 19개로 분산.
- 상품이 이미 있다: Remotion 그래픽 틀, 대본 말투 검사기, 쉼 규칙, 결과물 검사기, 유튜브 검사 도구.

## 형식
| 형식 | 주기 | 내용 |
|---|---|---|
| 롱폼 | 주 1 | "AI로 ~ 만들어 봤다" 실험 기록. 화면 녹화 + 결과 영상 + 비용·시간 숫자 |
| 쇼츠·릴스 | 주 3 | 롱폼 하나에서 숫자 하나, 실패 하나, 팁 하나 |
| 결과물 | 수시 | 1편 23.98p 같은 이야기 영상은 "AI가 만든 결과물"로 롱폼 안에 넣는다 |

## 일정
| 기간 | 할 일 | 확인할 숫자 |
|---|---|---|
| 1개월 | 채널 개설, 롱폼 4·쇼츠 12. 무료 자료(말투 검사기)로 "댓글 키워드 → DM" 연결 | 쇼츠 평균 조회수, 3초 이탈률 |
| 2개월 | 반응 좋은 쇼츠 주제를 롱폼으로 키움 | 롱폼 평균 시청 시간 |
| 8주 판단 | 쇼츠 평균 1,000회·롱폼 500회 미만이면 같은 제작 틀로 "일상 속 왜"(광고형)로 전환 | |
| 3개월 | 자동화 키트 1차 판매 (3만~5만 원) | 판매 수, 문의 수 |
| 4~6개월 | 수익화 조건(구독 1,000 + 4,000시간) 도전, 키트 2차 | 월 수익 |

## 현실적인 수익 범위 (6개월 차)
- 키트 월 10~30개(30만~150만 원)가 가장 큰 몫. 광고는 수익화 조건을 넘더라도 월 수만~수십만 원.
- 월 100만 원은 6개월 차에 "가능하지만 보장 못 하는" 목표.

## 역할
- Claude: 조사, 대본, 그래픽, 음성, 렌더, 검사, 업로드 파일·설명란 준비.
- 사용자: 대본 승인, 업로드(YouTube·인스타), 주 2~3시간.
