# 롱폼 말투 규칙: 옛날 이야기를 들려주는 선배

릴스 규칙(`docs/PERSONA.md`, 결론 먼저)과 따로 쓴다. 롱폼은 "옛날 이야기로 공부하는 영상"이다.

## 참고 채널과 가져올 점
| 채널 | 가져올 점 |
|---|---|
| LEMMiNO | 장면으로 시작하고, 답을 조금씩 늦게 보여 준다. 조용한 화면과 음악으로 긴장을 만든다 |
| Vox (Darkroom 시리즈) | 옛날 문서·사진을 화면에 띄워 "그날 무슨 일이 있었나"를 기록으로 따라간다 |
| Technology Connections | 기술의 옛날 사정을 친구에게 설명하듯 말한다. 중간에 "그런데 여기서 문제가" 하고 방향을 튼다 |
| Asianometry | 회사·사람·결정 순서로 기술 역사를 하나의 사건처럼 풀어 간다 |
| 안될과학 (한국어) | 어려운 과학을 한국어 이야기 말투로 푸는 방식 |

## 구성
1. **첫 5초만 지금 화면.** 답은 말하지 않고 "이 숫자에는 두 번의 결정이 숨어 있습니다"처럼 궁금증만 남긴다.
2. **그다음은 일어난 순서대로.** 장마다 "언제, 어디서, 누가"로 시작한다.
3. **장마다 문제 하나.** 문제가 생기고 → 사람들이 고민하고 → 결정한다. 장 끝에서 다음 문제를 예고한다.
4. **답은 한 번만.** 숫자(24, 29.97, 23.976)는 그 숫자가 정해지는 장면에서 처음이자 마지막으로 크게 보여 준다.
5. **정리 문단을 영상에 넣지 않는다.** 정리는 고정 댓글과 설명란으로 옮긴다. 마지막은 지금 카메라 화면으로 돌아와 한두 문장으로 끝낸다.

## 문장
- 결론을 먼저 말하지 않는다. 장면 → 문제 → 결정 순서.
- 끝맺음을 섞는다: "~했습니다", "~였죠", "~던 겁니다", 질문. 같은 끝맺음은 세 번 연속 쓰지 않는다.
- 짧은 문장과 긴 문장을 섞는다. 장면이 바뀌는 곳에는 짧은 문장을 둔다("1953년. 26년이 지났습니다.").
- 사람은 이름과 하는 일로 부른다("웨스턴 일렉트릭의 기술자 스탠리 왓킨스"). 처음 한 번만 길게, 다음부터는 이름만.
- 기록에 남은 말만 따옴표로 쓴다. 대사를 지어내지 않는다.
- 비유를 쓰지 않는다. 확인 안 된 사실은 쓰지 않는다. (릴스 규칙과 같음)
- 같은 숫자·같은 결론을 한 장 안에서 두 번 말하지 않는다.

## 화면
- 장면 그림이 먼저, 숫자 그림은 결정되는 순간에만.
- 장면 그림: 극장, 영사실, 녹음실, 거실, 회의실, 문서(재연 표시).
- 사람 실루엣이 움직이는 장면을 장마다 하나 이상 넣는다.
